# Scenes

Scenes represent composed mimic layouts that bring together multiple components and connecting piping into operational views.

## Available Scenes

- [Boilers Scene](/mimics/modules/boilers-module) - Initial documentation page for the BoilersScene composition

## Purpose

Scene documentation is used to describe:

- Which component instances are included
- How components are positioned and oriented
- Which piping segments connect the instances
- Scene-specific notes and future implementation details
